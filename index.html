Termos de Uso — JobNow

Ao utilizar o JobNow, você concorda com estes Termos de Uso.

1. Utilização da plataforma

O JobNow disponibiliza ferramentas para criação, edição e exportação de currículos profissionais. O usuário é responsável pelas informações inseridas na plataforma.

2. Conta do usuário

O usuário deve fornecer informações verdadeiras, manter suas credenciais protegidas e não utilizar a conta de terceiros.

3. Currículos

O usuário é responsável pelo conteúdo de seu currículo.

4. Uso permitido

A plataforma não deve ser utilizada para fraude, falsificação de documentos, impersonação ou qualquer atividade ilegal.

5. Alterações

O JobNow poderá atualizar suas funcionalidades e estes termos quando necessário.

Política de Privacidade — JobNow

Esta política explica como os dados fornecidos pelo usuário são tratados nesta versão da plataforma.

1. Dados coletados

O JobNow pode armazenar nome, e-mail, senha, informações profissionais, localização profissional, currículo e demais informações fornecidas pelo usuário.

2. Armazenamento

Nesta versão de demonstração, os dados são armazenados localmente no navegador por meio do recurso localStorage.

3. Uso dos dados

Os dados são utilizados para permitir o funcionamento do gerador de currículos e manter as preferências do usuário.

4. Senhas

Esta versão é um protótipo. Para produção, senhas não devem ser armazenadas diretamente no navegador.

5. Exclusão

O usuário pode apagar os dados locais removendo os dados do site nas configurações do navegador.

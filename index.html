Termos de Uso — JobNow

1. Utilização da plataforma

O JobNow disponibiliza ferramentas para criação, edição e exportação de currículos. O usuário é responsável pelas informações inseridas na plataforma.

2. Conta do usuário

O usuário deve fornecer informações verdadeiras, proteger suas credenciais e não utilizar contas de terceiros.

3. Currículos

O usuário é responsável pelo conteúdo de seu currículo e pelas informações fornecidas.

4. Uso permitido

A plataforma não deve ser utilizada para fraude, falsificação de documentos, impersonação ou atividades ilegais.

Política de Privacidade — JobNow

1. Dados coletados

O JobNow pode armazenar nome, e-mail, senha, informações profissionais e dados fornecidos pelo usuário.

2. Armazenamento

Nesta versão de demonstração, os dados são armazenados localmente no navegador através do localStorage.

3. Uso dos dados

Os dados são utilizados para permitir o funcionamento do gerador de currículos e manter as preferências do usuário.

4. Segurança

Esta é uma versão de demonstração. Uma implementação de produção deve utilizar servidor, HTTPS, banco de dados e hash seguro de senhas.
